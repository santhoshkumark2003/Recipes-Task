# Recipes Task

## Project Description
A full-stack MERN application for  created with Node.js, Express.js, and MongoDB.

## Tech Stack
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **API Testing**: Postman

## Features
- View, create, and manage recipes

### Prerequisites
- Node.js installed
- MongoDB running locally or cloud connection
- Postman installed (for API testing)


# Install backend dependencies
cd backend
npm install

## Usage
```bash
# Start backend server
npm start

The server will run on `http://localhost:5000` by default.

## API Testing
Import the Postman collection from `/backend/postman` to test API endpoints.
